# Patricia Belli 中文作品图册

非官方学习与研究整理，依据艺术家官网及其提供的两本官方图录。

- 官网六个板块51个展示条目，图录补遗46个阅读条目。
- 237张作品及细节图、44张官网页面截图、16个官网视频入口。
- 包含材料、构成、故事背景及理念与延伸解读。
- 中文标题为工作译名；材料、年份与版本的未决差异在图册中标注。

这不是艺术家全部生涯作品的编年全集，也不是艺术家官方网站。
作品、图片和原图录的版权属于艺术家、摄影者及相应出版机构；不对这些内容授予开源许可。
